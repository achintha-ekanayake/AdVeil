# Security Policy

AdVeil runs on every page you visit and can modify page content and network requests, so security issues are taken seriously.

## Reporting a Vulnerability

Do not open a public issue for security reports. Instead, use [GitHub's private vulnerability reporting](../../security/advisories/new) for this repository, or contact a maintainer directly.

Include the affected version, a description of the issue, and reproduction steps if possible. Expect an initial response within a few days.

## Supported Versions

Only the latest released version is supported with security fixes.
